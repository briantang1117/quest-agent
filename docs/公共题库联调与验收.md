# 公共题库联调与验收

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

已接线：PC题库列表/详情 → Java公共库/任务/原件存储 → Python文本抽取或PDF预检 → Java逐题草稿 → PC编辑/证据核对/确认/发布。公共库按试卷维护，科目与考试类型来自接口枚举；题号可空且为正整数，题型仅单选/多选。

非结构化原文提交由显式有界执行器处理；文本层PDF上传先预检，生成候选/逐题任务，用户点击开始仅处理该批次。全局扫库`quest.public-import.enabled`与显式任务执行分开。原件`file_bytes`存PG，下载经Admin鉴权，不是匿名S3地址。

草稿具有版本校验、导入人确认、发布及批量发布；发布题先下架再维护，删除为软删除。普通用户选题只取已发布且未删除内容。失败与歧义保留任务状态，不自动发布、不因上游失败重复付费调用。

来源证据组件与多源候选图已有代码，但扫描PDF/截图/图片的OCR自动分段、证据采集到完整Admin工作流尚未完成；详[证据层](多来源导入证据层设计.md)。

核查入口：`PublicBankController/Service`、`PublicBatchExecutor`、`PublicImportProcessor`；Python`api/public_import.py`、`api/pdf_import.py`、`parser/pdf_runner.py`；PC`AdminBanksView`、`AdminBankDetailView`、`AdminQuestionView`。

本机验收：以合成单选/多选分别走文本与文本PDF；检查草稿题号/答案/引用是否可核对、未确认拒绝发布、版本冲突、下架/软删除不可再抽取、原件不匿名访问、重复请求不扩大处理范围。真实题库批量下架/删除属于真实数据操作，本轮文档整理未执行。
