# 考纲管理与检索验收

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

Java`SyllabusController/Service/Pipeline/Chunks`、Python`api/syllabus.py`及考纲parser/review、PC`AdminSyllabiView`及详情页构成现有链路。

当前实现：带考试/年份/版本/来源元数据的PDF上传；离线页文与章节；AI审核/人工编辑启用；发布与归档；数据库持久化审核/索引任务；切片、Embedding缓存与模型/维度校验；失败重试和重建索引；下载原件；普通用户按科目年份查看；新会话绑定已发布版本，历史绑定可按约束读取归档版本。

向量写入`syllabus_chunk.embedding`（pgvector，不固定1024维）。召回先限制版本、generation、科目、启用状态、Embedding模型与维度，再加载有限候选在Java算余弦，不是PG ANN/HNSW查询。失败走同一版本关键词降级；无目标年份不能臆造考纲。旧`question_embedding vector(1024)`不供新考纲混用。

适用范围当前单值建模；多选改造、混合召回/重排、大规模ANN仍是后续建议。流水线是否能在真实环境完成还取决于数据库版本、Embedding供应商和实际资料，本次未连接核验。

验收重点：多年份不得串版；不同模型即使维度相同也不得混向量；草稿不可绑定；归档不得成为新会话当前版本；AI整理不能擅自启用章节；审核失败/任务中断可显示并显式重试；重建时旧generation不误写；向量不可用的降级应可识别。
