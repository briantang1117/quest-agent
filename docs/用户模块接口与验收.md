# 用户模块接口与验收

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

实现：`UserController`、`UserService`、`SessionSecurityFilter`、`LoginLimiter`、`LoginSource`；前端`auth.ts`与登录/改密/用户管理页。接口目录见[api](api.md)。

不开放自助注册；Admin与Student角色互斥，管理员通过后台创建普通用户。密码BCrypt，令牌JWT；JWT之外查数据库会话与账号状态，退出、禁用、重置密码会影响后续身份验证。强制改密用户只能走相应受限流程。刷新后调用 /auth/me 校验身份，不保存密码或信任缓存角色。

Admin后台目前包括公共题库、考纲、用户和AI系统日志，不能再沿用“后台没有内容管理”的旧阶段限制。学生私人会话/学习资料接口仍检查所有者；当前系统审计详情有原文能力，不等同于所有业务内容均禁止在审计中出现。

个人私库与用量统计尚未实现。旧SQL结构和预留字段不能当作功能完成。

验收：匿名业务401；Student不能用Admin路由；Admin不能刷题；改密前后的旧Token、禁用后会话和退出会话失效；伪造X-Quest-Client-IP不能绕过来源处理；不同用户会话/资料不可互读。数据库测试使用H2，不代替真实PG迁移与会话核验。初始化仅使用[专用交互入口](../backend/api-java/docs/用户模块与安全初始化.md)，不在日常启动自动建Admin。
