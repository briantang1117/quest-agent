# Agent能力实现清单

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

只统计本项目应用代码，不把开发助手的工具、Skill或MCP能力算入产品。

| 能力            | 代码现状                                                                          | 边界                                                                               |
| --------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 意图与动作路由  | coach-route识别，Java决定实际动作                                                 | 模型不决定权限、发布或最终判分                                                     |
| 受控工作流      | 提取/候选/旧coach-turn使用LangGraph；考纲/资料另有状态任务                        | 并非全部由LangGraph编排                                                            |
| 流式结构化输出  | SSE参数拼装、顶层reply解析、完整JSON校验、取消/错误                               | 自动决策轮缓冲正文，首段等确认无工具后再显示                                       |
| 记忆            | 会话与偏好持久化，有限历史上下文                                                  | 无长期语义记忆/自动记忆治理                                                        |
| Tool Use        | get_current_time/search_web/fetch_page schema、执行器、观察回传、去重、来源、审计 | 默认true，本地时间始终注册，网页能力未配置不注册，未作答题禁外发，真实供应商待验收 |
| ReAct式行动循环 | 默认六轮工具请求/十二次调用（可配置）、观察后继续、最终收敛                                       | 普通异步循环，不展示推理链；无通用高副作用Agent                                    |
| RAG             | 考纲切片/Embedding/PG向量保存/版本约束/Java余弦/关键词降级                        | 无完整私人RAG；无PG ANN/混合重排实装                                               |
| 类似题/自适应   | 现有基础抽已发布题、Java判分                                                      | 相似题工具、掌握度驱动策略待做                                                     |
| 应用级Skill     | 无版本化能力包注册/发现执行机制                                                   | 提示词和编程助手Skill不是产品Skill                                                 |
| MCP             | 无应用MCP server/client                                                           | 内部HTTP与工具schema不是MCP                                                        |
| OCR/多模态      | OCR适配器及图片输入安全校验                                                       | 未接扫描PDF/截图导入完整链路                                                       |
| 异步资料        | 快照、事务outbox、MQ Worker、租约、显式重试、Markdown                             | 功能与Worker默认关闭，真实MQ需单独验收                                             |
| 可观测性        | 业务调用审计、工具哈希/耗时/类别、管理日志页面                                    | 非每次内部模型请求的完整token/费用账本                                             |

入口详[架构](架构说明.md)、[工具技术说明](陪练工具技术说明.md)、[项目现状](项目现状.md)。新增能力必须有实际触发入口、状态/失败行为、测试证据与真实环境限制，不能仅凭命名或数据库表标完成。
