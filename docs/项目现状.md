# 项目现状与实现证据

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

本轮从Controller、Service、Python路由、前端Router/页面、依赖与迁移核对。产品目前已超出基础脚手架，主要闭环是“公共内容建设 → 对话练习与讲解 → 考纲引用/联网补充 → 会话资料整理”。

## 核查入口

- Java：`backend/api-java/src/main/java/com/quest/api/{auth,publicbank,coach,syllabus,materials}`；领域判分在`backend/common`；MQ流程在`backend/worker-java`。
- Python：`app/api`、`app/agent`、`app/llm`、`app/providers`、`app/parser`（相对`backend/ai-python`）。
- 前端：`frontend/pc-web/src/router/index.ts`与views、`frontend/shared/src/*-api.ts`；移动对照`frontend/mobile-agent/src/views`。
- 迁移：API resources及deploy/migrations均有V1–V13；应保持同名内容一致。旧`question_embedding`固定1024维，与考纲新向量结构分开。
