# 公共题库 PDF 导入开发计划

> 执行方式：按可测试交付分阶段推进；首段为模型工具适配与PDF本地预检，随后实现Java编排/审核与PC后台，不把首段当成整条业务完成。

**Goal:** Admin上传PDF创建公共客观题库，抽取原答案/解析，缺失部分由模型补全，按需联网核验，审核后对普通用户发布。

**Architecture:** Java拥有公共库/导入任务/草稿/审核/发布与S3授权；Python FastAPI+LangGraph执行受控解析与生成；PC Arco后台提供题库管理。平台公共内容与用户私有内容分域，Admin可以管理公共内容但不能读用户私有题库/对话；Admin仍不可刷题。

**Spec:** 用户2026-11-08后续决定覆盖原“本期不做公共库/Admin只开户”条款。原私有边界继续保护个人数据，个人多库功能暂缓。本期单选/多选，不开发主观题。

## 模型实测（2026-11-08）

每能力独立Key，不借用或自动换址；仅合成/公开内容一次最小请求，未上传真实PDF。

| 能力 | 实测端点 | 模型/结果 |
|---|---|---|
| 文本 | Thinklight /v1/chat/completions | deepseek-v4.1-flash，HTTP200且JSON有效 |
| 视觉/OCR | Ark /api/plan/v3/chat/completions | doubao-seed-2.1-pro，HTTP200，纯蓝图识别蓝色 |
| 向量 | Ark /api/plan/v3/embeddings/multimodal | doubao-embedding-vision，HTTP200，实际2048维 |
| 搜索 | DeepSeek /v1/tools/search | HTTP200，1结果 |
| 抓取 | DeepSeek /v1/tools/fetch | HTTP200，公开网页正文 |

当前PG向量列1024维，**不写2048向量进旧列，不自动改表**。后续新索引迁移独立授权；本期PDF导入无需先做向量索引。

## 全局约束

- 源PDF/原页码/题号及原答案引用可追溯；原答案优先，模型不得静默覆盖；答案冲突进入待核验。
- 模型产出默认草稿，缺图/含糊/截断/不完整题标记待处理，不猜补图形题。
- 搜索结果为不可信资料，保留来源与检索时间，历史题采用当年法规适用边界；不将网页文本当工具指令。
- 文件有体积/页数/解码上限、类型校验，解析离线预检不执行嵌入脚本。真实PDF云端调用需明确范围/预算，不因本地存在样本就整卷外发。
- 搜索/抓取独立端点，模型调用独立配置；请求无自动付费重试，429/配额/鉴权失败明确区分且脱敏。
- 不停止用户IDE进程，不写NAS/创建公共桶策略/迁移或改变现有账号权限，直到对应操作明确批准。
