## 设计裁决

1. Admin和Student为互斥账号类型；当前不开放自助注册、Admin提升接口、内容浏览与代用户登录。
2. 使用短期JWT和数据库会话，2h过期；撤销依赖服务端状态，不等Redis适配器落地后才实现禁用生效。
3. 初版为内存token；用户后续明确要求持久化，已改localStorage仅存token/expiresAt/baseURL，刷新后/auth/me通过才恢复身份，不信任缓存角色、不保存密码。2h有效期不变，无Refresh Token；记录同源脚本读取风险，后续生产可升级HttpOnly Cookie。
4. 用户列表只返回账号元数据，未来题库归属尚未落地，不伪造用量数字，也不统计/泄露跨用户内容。
5. 所有ID以字符串wire传输，前端不把BIGINT ID转为不安全的Number。
6. 日常Flyway默认关闭，V1–V3不重写；新增SQL单独评审，兼容副本同步后再经授权迁移。
7. 登录限流首期按单实例实现；正式多副本/重启后的全局限制需后续接共享Redis，不能冒充已完成。
