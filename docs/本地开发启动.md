# 本地开发与验证

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

应用在Mac本机，NAS只提供中间件。以下命令从仓库根执行，已有环境配置不要被模板覆盖。

| 工程     | 本地配置                         | 入口                                 | 默认端口 |
| -------- | -------------------------------- | ------------------------------------ | -------- |
| API      | backend/.env.api.properties      | bash backend/scripts/start-api.sh    | 8080     |
| Worker   | backend/.env.worker.properties   | bash backend/scripts/start-worker.sh | 无Web    |
| Python   | backend/ai-python/.env           | bash backend/ai-python/start.sh      | 8000     |
| PC       | frontend/pc-web/.env.local       | bash frontend/start-pc.sh            | 5173     |
| 移动骨架 | frontend/mobile-agent/.env.local | bash frontend/start-mobile.sh        | 5174 /m/ |

Java工作目录backend；IDE只打开api-java时工作目录设为其父目录。原生Run/Debug使用ApiApplication或WorkerApplication，不能运行common；API选deployment并显式`--spring.flyway.enabled=false`。Java wrapper隔离公司Maven设置，勿改全局settings。Python脚本显式`uv run --env-file`，Settings不会自行读.env；默认仅127.0.0.1且关闭访问日志。前端开发服务监听0.0.0.0，/gateway代理8080，正式同源用VITE_API_BASE_URL=/。

首次配置参考各工程.example，仅在文件不存在时复制。Python文本模型采用完整TEXT_LLM_*组优先，OCR/Embedding/Search/Fetch密钥独立。COACH_TOOLS_ENABLED默认true；没有配置的工具不注册。资料API需要quest.materials.enabled，Worker需要QUEST_MATERIAL_MQ_ENABLED，二者默认false且不是同一开关。资料Topic必须预先就绪；旧OUTBOX_ENABLED保持false。

构建与离线检查：

```bash
./backend/mvnw -B -ntp clean verify
uv --directory backend/ai-python sync --group dev --frozen
uv --directory backend/ai-python run pytest -q
uv --directory backend/ai-python run ruff check --no-cache .
uv --directory backend/ai-python run ruff format --no-cache --check .
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend lint
pnpm --dir frontend format:check
pnpm --dir frontend test
pnpm --dir frontend typecheck
pnpm --dir frontend build
uv run --with python-dotenv --with pyyaml --with pglast python -m unittest discover -s scripts/tests -v
```

启动脚本会package并跳过测试，不能代替verify。API/common局部验证可用`./backend/mvnw -B -ntp -pl api-java -am verify`；Worker单独用`-pl worker-java -am verify`。

只读检查`GET http://127.0.0.1:8080/actuator/health/readiness`和Python`GET http://127.0.0.1:8000/health/live`。API匿名业务401属预期；local健康不证明PG连通；deployment readiness才包含数据库。已有用户自行初始化的Admin不要重复bootstrap。修改后由用户重启其IDE服务，不批量杀进程，不运行根Compose重复创建中间件。
