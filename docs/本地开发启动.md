# 三个 IDE 独立开发启动手册

**应用运行在Mac，中间件在群晖；不要在群晖部署应用，不重复创建PG/Redis/SILO/MQ。**

## 分别打开这些目录

| IDE | 打开的目录 | 启动方式 | 说明 |
|---|---|---|---|
| IntelliJ IDEA | `backend/` | Quest API / Quest Worker，或 Native Debug | Java27、Maven、Spring Boot，不依赖Python/uv |
| PyCharm | `backend/ai-python/` | Quest AI / start.sh，或原生Python配置 | 独立uv.lock、.venv和.env |
| WebStorm | `frontend/` | dev:pc / dev:mobile，或Quest PC/Mobile | 独立pnpm workspace与lockfile |

不需要各IDE打开整个大仓库；日常启动不读取仓库根.env/deploy凭据。前端PC/移动共享shared，因此前端整体作为一个独立工程；Java的common/API/Worker作为一个Maven多模块工程。

## 首次配置

Java（backend工作目录）：

```bash
# 仅第一次，已有真实文件不要覆盖
cp .env.api.properties.example .env.api.properties
cp .env.worker.properties.example .env.worker.properties
./mvnw -B -ntp clean verify
```

Python（backend/ai-python工作目录）：

```bash
uv sync --group dev --frozen
cp .env.example .env
```

前端（frontend工作目录）：

```bash
pnpm install --frozen-lockfile
```

前端已有pc-web/.env.local和mobile-agent/.env.local，默认/gateway代理本机8080；这些都是非敏感地址配置，不填任何后端secret。

**2026-11-07经用户明确批准，真实配置已迁入三个独立工程文件，本机无需再复制模板。** backend/.env.api.properties、backend/.env.worker.properties、backend/ai-python/.env均已创建且权限0600；没有覆盖已有文件、修改源配置或输出凭据，没有复制SSH、PG超级用户或MinIO root密码。Worker不含迁移owner凭据。Java已从backend工作目录加载自身配置连接NAS，备用端口数据库readiness200/UP；Python使用自身.env健康200/alive。

Java使用Properties语法，不是dotenv；不要给密码加引号，反斜杠需转义。Python用dotenv。两边的内部服务token/HMAC保持相同，不传SSH或PG超级用户凭据。Worker不持有数据库owner密码。

## 日常独立命令

IDE Run配置也执行相同逻辑：

```bash
# IDEA工程终端，cwd=backend
bash scripts/start-api.sh
bash scripts/start-worker.sh

# PyCharm工程终端，cwd=backend/ai-python
bash start.sh

# WebStorm工程终端，cwd=frontend
pnpm dev:pc
pnpm dev:mobile
# 或 bash start-pc.sh / bash start-mobile.sh
```

Java Shell先Maven package再exec java；**IDEA Native Debug直接main+Make，不需要打JAR、不经过Python**。Java改代码重新Run；Python/前端热更新。

旧根目录scripts/dev.py仅保留兼容转发到各子工程入口，不再在日常启动时统一读取大仓库凭据。旧的service_environment仅用于历史迁移脚本/测试，不是推荐运行入口。

## 地址与启动顺序

1. API：http://127.0.0.1:8080/actuator/health
2. PC：http://localhost:5173/practice
3. AI需要时：http://127.0.0.1:8000/health/live
4. 移动需要时：http://localhost:5174/m/sessions
5. Worker目前Outbox关闭、无Web端口，可暂不运行。

只看页面不必启动五个。手机访问前端用Mac局域网IP，不是群晖IP；前端监听0.0.0.0，只在可信网络使用，其/gateway可转发到本机后端。

停止：对应IDE红色Stop或终端Ctrl+C。不要同时运行同一服务的两份配置；旧服务还占用端口时先停止对应本项目进程，不要pkill全部Java/Python/Node。
