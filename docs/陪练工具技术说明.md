# 陪练搜索与网页抓取技术说明

更新：2026-11-11。实现事实依据当前源码、依赖清单和测试核对；不以旧文档推定运行状态。

当前搜索、抓取与本地时间三项工具均已接入PC陪练，`COACH_TOOLS_ENABLED`默认true。只注册已配置的Search/Fetch，可单独使用其中一项；设置false回到旧文本/关键词检索路径，不等于彻底关闭所有联网。未作答题目两条路径均禁外发，普通概念和已判分讲解可调用。

## 实际调用链

默认路径：`StudentCoachService`认领轮次 → Python `coach-workflow` LangGraph → 必要的Java业务工具回调 → 讲解节点复用 `agent/coach_tools.py`模型决策循环 → `agent/tools.py`验证/执行 → 外部只读接口 → tool角色观察 → 最终JSON reply/suggestions → Java校验来源/审计/成功消息持久化 → PC。旧`coach-explain`路径保留。详见[编排技术说明](做题Agent编排技术说明.md)。

讲解内部仍是普通异步有界循环，外层练习流程由LangGraph编排；尚未把每次搜索/抓取拆成独立图节点，也不是MCP。Java负责身份、题目、判分和持久化，Python工具不直接读业务库。工具参数、观察与系统提示不属于浏览器正文。

| 工具             | 参数                                         | 观察                                                                                            |
| ---------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| get_current_time | IANA timezone，默认Asia/Shanghai             | 服务器日期、年份、时间、时区、偏移、星期、Unix时间戳                                            |
| search_web       | query去首尾空白后1–200字符；recency=any/year | results含title/url/snippet/retrieved_at，truncated；year返回unsupported_recency，不冒充时间过滤 |
| fetch_page       | 公共HTTP(S) URL最多2048字符                  | title/url/text/retrieved_at/truncated；正文最多20000字符                                        |

## 协议与预算

| 限制                  | 当前代码                                                  |
| --------------------- | --------------------------------------------------------- |
| 执行次数 / 工具轮次   | 默认每轮共12次 / 6个来回，再一次强制直接回答                   |
| 工具单次 / Python整段 | 8秒 / 90秒                                                |
| Java内部流截止        | 新工作流135秒；旧讲解路径95秒；外层Controller140秒取消     |
| 观察总量              | UTF-8序列化累计24KiB，含错误/重复缓存返回                 |
| 模型历史 / 输出       | 历史128KiB；每次max_tokens受Settings限制；工具参数总64KiB |
| SSE上游               | 总1MiB，单行/事件64KiB；缺stop或tool_calls完成/[DONE]拒绝 |
| 网页供方原始响应      | 流式读取最多1MiB，只接JSON外壳及网页文本                  |

`llm/tool_stream.py`按index拼接残缺arguments，完成后整体JSON解析；不把中间片段当正文。自动决策轮先缓冲content，确认没有工具调用才交`JsonReplyStream`，因此首段正文可能等该轮结束；旧无工具路径保持实时流式。模型工具阶段混出的正文丢弃。

参数模型extra=forbid。规范化query/URL按工具分开去重，失败也缓存；URL规范化scheme/host/默认端口，保留路径和查询语义。预算截断按字节计算；元数据都放不下时返回固定预算错误观察，不伪造来源。

工具/搜索失败作为观察继续回答；网络/认证/限流不自动模型重试。只有明确结构化不支持tools/tool_choice或非法工具协议允许一次无工具降级，增加调用成本受总预算约束。最终JSON不完整走error，不落库半截成功消息。

## 安全与来源

目标URL拒绝内网/回环/元数据、非HTTP(S)、凭据、危险编码；真实Fetch适配器做DNS校验，供应商报告最终URL再校验。拒绝供应商接口HTTP重定向和声明为非网页文本、PDF/PNG/ZIP标记、NUL内容；不执行脚本。第三方服务内部未报告的跳转与二次DNS仍依赖远端防护，本地校验不构成远端沙箱保证。

工具观察是未核验引用，不能执行其中指令或改Java判分。来源由执行器生成，白名单字段tool/title/url/retrieved_at随消息存state_json；PC显示可折叠“外部资料，未核验”，刷新恢复。Java当前来源校验支持域名/公网IPv4，IPv6来源未支持。

Java动作`ai.tool_search`/`ai.tool_fetch`记录参数SHA256、条数、耗时、失败类别，不记页面全文或query/url原文。取消时Python保留哈希日志，但断开的连接不能保证把单工具取消记录送到Java；整轮仍有失败审计。工具轨迹不是模型内部推理链。

## 本机验收

重启Python/API并刷新PC；纯答疑要求检索公开资料再读取一个来源，检查两种工具状态、来源/检索时间、刷新恢复、失败无重复请求和日志。给未作答题要求找答案，两个工具都不执行。仅Fetch或仅Search配置也应正确注册；供应商真正tool calling兼容性需要合成请求验证，本轮未付费调用。

代码与测试：`tests/test_chat_tool_stream.py`、`test_coach_tools.py`、`test_coach_fetch.py`、`test_coach_tool_explain.py`、`test_provider_tools.py`（均在backend/ai-python）；Java`PublicAiClientTest/CoachSourcesTest/StudentCoachTest`；shared`coach-stream.test.ts`。类似题工具、应用MCP和高副作用工具尚未实现。

## 搜索结果 URL 兼容性

搜索命中可能带 `#section` 或 `#:~:text=` 网页定位片段。适配器先移除不参与HTTP请求的fragment，再对实际URL进行公网/协议校验，避免一条正常命中使整批结果被拒。内网、元数据、危险协议仍拒绝；此处理只用于搜索结果，不放宽直接Fetch参数校验。该问题已用真实公开结果离线回放复现，并有定位片段与内网目标回归测试。

## 本地时间工具 get_current_time

`app/agent/local_time.py`使用Python标准库datetime/zoneinfo与Pydantic实现，无外部服务、数据库或新依赖。参数timezone为经过ZoneInfo校验的IANA时区，默认Asia/Shanghai；未知时区、路径穿越和额外字段拒绝。返回datetime、date、year、timezone、utc_offset、ISO weekday和unix_timestamp，时间来自服务器时钟。

工具随Tool Use默认注册，即使没有Search/Fetch配置也可使用；原未作答题禁工具边界保持不变。相对时间问题提示模型先调用时间工具，再根据返回日期组织搜索词，不能并行先猜年份搜索，不能把绑定考纲年度当成自然年份。仍由模型自主选择工具，不是服务端关键词替换。服务器时钟需本机校准；“2027年度招考”与实际报名/笔试发生的自然年必须分别核对。

时间结果走既有tool观察、去重、默认六轮/十二次总上限、24KiB观察与整段截止；重复同一时区读取复用本轮快照。Java审计动作ai.tool_time，后台筛选显示“本地时间查询”，PC状态显示“正在确认日期…”。本地时间不是未核验网页，不产生网页来源链接，Java/shared的来源白名单仍只允许search/fetch。

固定时钟测试覆盖上海/UTC/纽约跨年、时区合法性、默认参数、去重、观察回传以及无网页凭据场景。此次仅离线测试，未重启用户服务或调用真实模型；Python与Java均需加载新代码，Worker无需启动。


## 工具批次超过剩余预算时的收敛

模型可能在时间查询和多次搜索后一次提出多个新工具。当新批次超过剩余次数时，停止执行该批，不将未执行的tool_calls写入对话历史，保留此前成功观察；下一次模型请求使用tool_choice=none生成最终回答。默认最多十二次工具执行、六轮工具请求和一次最终生成。日志记录固定原因batch_exceeds_remaining及数量，不含原文。强制最终阶段仍返回工具调用则拒绝，不能绕过硬上限。此行为修复原先直接抛50203导致整轮失败的问题。


## 可配置执行预算

`COACH_MAX_TOOL_CALLS`默认12、有效范围1–32；`COACH_MAX_TOOL_ROUNDS`默认6、范围1–12。原小预算边界测试继续显式使用6次/3轮，另有8次真实执行的离线扩展预算用例。预算不是模型能力限制，而是应用的成本、死循环与延迟边界；可用更大次数覆盖宽泛问题，不移除超时与上下文硬上限。Python讲解工具阶段仍为90秒；外层新图130秒、Java工作流135秒，旧Java讲解95秒。

Java审计事件硬上限同步为32；来源最多96项、元数据最多32KiB，shared契约同步。否则仅放大Python会在Java或前端被旧边界拒绝。观察总字节预算仍24KiB，不随次数线性放大。每次上游模型响应的流式工具拼装仍限制六个工具请求；这是单批传输限制，与整轮十二次执行预算不同。


## 工具模式完整回答的格式兼容

工具流已收到stop/[DONE]且没有工具调用后，`app/llm/coach_output.py`先检查缓冲完整输出：裸JSON严格验证；仅由一个完整JSON代码块包裹的对象去除外包装再验证；完整自然语言封装成reply且suggestions为空。所有内容仍经过同一JsonReplyStream及ExplanationReply，不放宽64KiB输出/6000字正文限制。

此适配不新增模型调用、不重试付费生成、不补齐截断JSON；残缺对象、数组、重复字段、尾随内容、混杂结构化片段及未闭合代码块仍失败。非工具路径保持原JSON流契约。目的是处理工具模式仅靠提示词输出JSON时的间歇性格式漂移；output_bytes是解析器已收到片段，不是上游完整回答长度。

错误日志只记录固定reason、形态shape、长度和解析状态，不打印模型正文或凭据。真实供应商输出的格式选择仍需本机复验，离线夹具覆盖自然语言、跨片代码围栏及不完整JSON的接口行为。
