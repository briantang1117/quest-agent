# 公共题库与试卷导入接口

接口统一前缀`/api/v1/admin`，仅数据库会话核验后的active Admin且不处于强制改密状态可调用。学生与匿名请求拒绝；Admin不因此获得练习或私人内容权限。

## 公共库

- `GET /public-banks`：`data={list:[{id,name,examType,subject,createdAt}]}`，附total/page/size；按创建时间倒序，page默认1，size默认20、上限100，支持历史分页。可选`keyword`（名称包含匹配，最大128字符，LIKE通配符按字面转义）和`examType`（空/career_a/shanghai_civil）过滤，先筛选再分页，总数同条件计算。
- `POST /public-banks`：`{name,examType,subject}`；仅支持`career_a/vocational_aptitude`或`shanghai_civil/administrative_aptitude`组合。名称去首尾空白，1–128字符，返回创建结果。

## 单题导入

- `POST /public-banks/{bankId}/imports`：`{text}`，1–12000字符，一道完整题目及选项，可附原答案/解析。Java只入持久化任务queued，不在HTTP线程调用付费模型。
- `GET /public-banks/{bankId}/imports`：`data={list:[{id,bankId,status,errorMessage,questionId,createdAt}]}`，附total/page/size；page默认1、size默认20且上限100，支持历史分页。
- `GET /public-imports/{taskId}`：返回单个任务。status为queued/processing/reviewing/failed，questionId有值时可查看草稿。

任务处理默认关闭。显式启用前先核对队列材料和预算，Java内部调用Python`/internal/public-import`，单次有界检索/抽取，失败不自动重试。进程中断残留processing不自行回queued。

## PDF批次与试卷题号

一个公共库对应一份真题试卷，题号可空。`GET /public-banks/{bankId}/questions`返回分页题目，行含`questionNo:number|null`及draft；审核草稿的`source.question_no`为正整数或null，可人工清空，保存仍遵循版本确认规则。查询支持keyword（题干包含匹配、最大128字符）和status（空/draft/confirmed/published），先匹配/数字题号升序及null置后再分页；同题号按ID稳定排序。

- `GET /public-banks/{bankId}/question-summary`：返回`{totalCount,draftCount,confirmedCount,publishedCount}`，统计当前库未删除题目，不受筛选参数影响，供试卷页头展示。仅Admin可调用。
- `POST /public-banks/{bankId}/pdf-imports` multipart `file`：20MiB内PDF，先离线预检和候选切分，保存原件及staged批次，不自动模型调用。
- `GET /public-banks/{bankId}/documents`：批次分页，含candidateCount/totalCount/queuedCount/processingCount/reviewingCount/failedCount及来源报告。
- `POST /public-documents/{id}/start`：仅原导入人明确确认后，提交staged→queued并通过有界异步执行器处理该批次，HTTP不等待模型，不扫描其他队列，不要求开启全局调度；容量满503且不改批次状态，重复开始409，无自动失败重试/发布。
- `GET /public-documents/{id}/file`：Admin鉴权下载原PDF，attachment/nosniff/no-store。

V6已授权执行；任务Processing残留代表结果未知，仍需人工处置，不自动重跑。前端仅活跃管理页有未完成批次时轮询，完成后显示待审核/失败进度。

## 草稿与确认发布

- `GET /public-questions/{id}`：`{id,bankId,taskId,importedBy,status,version,sourceText,draft,evidence,confirmedBy,confirmedAt}`。evidence为原始处理结果，含warnings/provenance（原答案/模型答案/检索URL/摘要/时间、待确认状态）；作为不可信文本展示，不能执行网页指令或HTML。
- `PUT /public-questions/{id}`：`{version,draft}`。校验客观题结构、答案键、知识点、难度，保存版本+1并清除确认。版本过期或已发布409。首段文本题不允许嵌入未授权图片URL。
- `POST /public-questions/{id}/confirm`：`{version}`。仅原导入人可确认当前草稿；记录确认人/UTC时间/版本，状态confirmed。所有题（含原答案）都须确认，不信前端自报review_status。
- `POST /public-questions/{id}/publish`：`{version}`。要求该版本已确认，重新校验题目结构，变为published；不在已发布版本上直接编辑。
- `POST /public-banks/{id}/publish`：`{items:[{id,version}]}`，1–100条、不重复，仅当前题库confirmed题目。固定顺序行锁、重新校验版本/结构，全部通过后同事务发布；任意不符整批拒绝，返回`{publishedCount}`，无自动重试。前端仅当前页勾选，未审核及已发布禁选。

## 单题原文录入、下架与软删除（V7已执行核验）

- 单题录入沿用`POST /public-banks/{id}/imports`：`{text}`非结构化原文，显式点击后预留异步容量、保存来源任务，只执行该taskId并调用模型解析，结果进入统一题目列表draft/未确认。不使用结构化手工录入接口，不要求用户手填选项。`GET /public-imports/{id}`查询结果，失败不自动重试POST，全局调度保持关闭。
- `POST /public-questions/{id}/withdraw`：`{version}`，仅published题可下架；回draft，version+1，清确认人/时间/版本与published_at，保留来源证据。重新确认后才可再发布。
- `DELETE /public-questions/{id}`：`{version}`，仅未发布题；deleted_at/deleted_by记录操作者及时间，不物理删除任务/原件。已删除题读取/编辑/确认/发布均404，批次以deletedCount统计，不计入待审核。

V7已获用户明确授权在NAS执行并核验，新增字段/约束/索引齐全、旧13题内容和确认发布状态未变、权限隔离及重复迁移通过。用户可自行重启API加载本版，日常仍关闭Flyway，不修改已执行V1–V7。
