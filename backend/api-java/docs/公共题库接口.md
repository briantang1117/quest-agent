# 公共题库接口与处理边界

更新日期：2026-11-11。接口依据 PublicBankController，流程依据 PublicBankService、PublicBatchExecutor、PublicImportProcessor。

总览：[根 README](../../../README.md)、[项目现状](../../../docs/项目现状.md)、[架构说明](../../../docs/架构说明.md)、[本地开发启动](../../../docs/本地开发启动.md)。

接口基础路径 `/api/v1/admin`，要求管理员身份。返回统一 ApiResponse（code、message、data、traceId），PDF 文件下载返回二进制。

| 方法       | 相对路径                              | 行为                               |
| ---------- | ------------------------------------- | ---------------------------------- |
| GET / POST | `/public-banks`                       | 分页查询/创建题库                  |
| GET        | `/public-banks/{id}`                  | 题库详情                           |
| POST / GET | `/public-banks/{id}/imports`          | 提交文本/查询导入任务              |
| POST       | `/public-banks/{id}/pdf-imports`      | multipart 上传 PDF，文件上限20 MiB |
| GET        | `/public-banks/{id}/documents`        | PDF 文档列表                       |
| POST       | `/public-documents/{id}/start`        | 启动文档分批导入                   |
| GET        | `/public-documents/{id}/file`         | 下载来源 PDF                       |
| GET        | `/public-imports/{id}`                | 导入任务详情                       |
| GET        | `/public-banks/{id}/questions`        | 题目分页与过滤                     |
| GET        | `/public-banks/{id}/question-summary` | 题目汇总                           |
| GET / PUT  | `/public-questions/{id}`              | 审阅/编辑草稿                      |
| POST       | `/public-questions/{id}/confirm`      | 确认题目                           |
| POST       | `/public-questions/{id}/publish`      | 发布题目                           |
| POST       | `/public-banks/{id}/publish`          | 批量发布                           |
| POST       | `/public-questions/{id}/withdraw`     | 撤回                               |
| DELETE     | `/public-questions/{id}`              | 软删除                             |

编辑请求包含 version 与 draft；确认、发布、撤回和删除使用 version 做并发控制。文本导入请求为 `{ "text": "..." }`；创建题库包含 name、examType、subject；批量发布包含 items。精确字段与校验以 Controller 的 record 和 Service 为准。

PDF 上传与开始处理分离，来源文档、导入任务、候选题及发布题分别持久化；API 调用 Python 检查/解析 PDF 和生成候选，不由浏览器直连模型。PublicBatchExecutor 是 API 进程中的有界执行器，PublicImportProcessor 在功能开关启用时工作。这个流程不是 RocketMQ Worker 流程。

`quest.public-import.enabled` 默认关闭。需先核验 V5–V7 数据结构、Python 签名配置和模型外发范围，再开启导入；文件和业务记录通过数据库实现，不可根据 MinIO 配置样例声称来源 PDF 已进入对象存储。

相邻模块：考纲由 SyllabusController/Service/Pipeline 管理版本、人工编辑发布、后台整理、索引重建及同版本检索；学生教练使用已发布公共题目快照，Java 判分并经 Python 生成讲解，SSE 转发工具状态。其能力不等于已经具有独立的通用刷题、错题本或考试产品闭环。

测试源码包括 PublicBankModuleTest、PublicBatchExecutorTest、PublicAiClientTest、QuestionNumberTest；本次没有运行测试，也没有上传 PDF、访问 NAS 或调用真实模型。
